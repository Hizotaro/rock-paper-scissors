# Rock Paper Scissors

This project is a console-based Rock Paper Scissors game built as part of The
Odin Project Foundations course.

## Scope

The current version focuses on JavaScript game logic and browser console output.
A graphical interface is intentionally out of scope for this version and will
be addressed in a later lesson.

## Learning Goals

- Practice breaking a problem into smaller steps.
- Use JavaScript variables, functions, conditionals, and user input.
- Track game state and scores.
- Test each part of the game through browser developer tools.
- Practice making small, meaningful Git commits.

## Running the Project

Open the HTML page in a browser and use the browser developer tools console to
view the game's output.
