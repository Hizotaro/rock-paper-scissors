# Rock Paper Scissors

This project is a Rock Paper Scissors game built as part of The Odin Project
Foundations course.

## Scope

The current version is a browser-based game with button controls and a simple
responsive interface. The original console version was expanded during The
Odin Project's Revisiting Rock Paper Scissors lesson.

## Live Demo

[Play Rock Paper Scissors](https://hizotaro.github.io/rock-paper-scissors/)

## Features

- Choose rock, paper, or scissors with a button.
- Play one round at a time against a fresh computer choice.
- Track both scores in the page.
- End the game when either player reaches five points.
- Start a new game without reloading the page.

## Learning Goals

- Practice breaking a problem into smaller steps.
- Use JavaScript variables, functions, conditionals, and event listeners.
- Track game state and scores.
- Update page content through the DOM.
- Test behavior through browser developer tools.
- Practice working with feature branches and meaningful Git commits.

## Running the Project

Open `index.html` in a browser and choose a move to start playing. No build
step or external dependencies are required.
